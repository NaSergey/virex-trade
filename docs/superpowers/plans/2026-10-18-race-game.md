# Гонки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** пятая игра раздела — гонка трёх машин на монеты (`/games/race`): живые и боты, банк первому на финише, мины, падающие опоры, удары с неба.

**Architecture:** симуляция гонки — чистые функции в `backend/src/race/sim/`, копия у фронта в `frontend/src/entities/race/model/sim/` (тест сверяет побайтно). Сервер (процесс `ROLE=games`) держит лобби и гонки в памяти, считает гонку с задержкой 150 мс по нажатиям из сокета, деньги — REST и транзакции. Браузер рисует сцену на Canvas 2D (перенос эскиза), свою машину ведёт предсказанием той же физикой, чужие — интерполяцией.

**Tech Stack:** NestJS + Prisma + socket.io (канал `/games`), Next.js App Router + FSD, react-query, Canvas 2D, jest (бэк), vitest (фронт).

**Спека:** `docs/superpowers/specs/2026-10-18-race-game-design.md`. **Эталон вида:** `docs/superpowers/specs/2026-10-18-race-sketch.html`.

## Global Constraints

- Ставки: 10, 50, 100, 500 монет. Банк = ставка × 3. Ожидание живых — 15 000 мс.
- Задержка суда `DELAY_MS` = 150; такт сервера — 50 мс; шаг симуляции — 1/60 с.
- Опасности объявляются на `ANNOUNCE` = 0,3 с вперёд.
- Машины: Стрела 6150 / 2500 / руль 2,1 / 2 удара / knock 0,5 / stun 0,8; Багги 5600 / 2800 / 2,4 / 3 / 0,55 / 0,75; Броневик 5600 / 2000 / 1,6 / 4 / 0,82 / 0,4.

- Сокет не двигает деньги: монеты — только REST и транзакцией.
- Бот подписан «бот» в лобби и итогах.
- Виды монет: `RACE_STAKE`, `RACE_WIN`, `RACE_REFUND`. Источник опыта: `game.race` (5, потолок 100 в сутки), начисляется на старте.
- Адреса — `/api/games/race*` (маршруты Caddy и rewrites Next уже есть).
- Файлы `sim/` у бэка и фронта совпадают побайтно; правка физики — правка обеих копий.
- Код на TypeScript strict; комментарии и тексты — по-русски, как в проекте; классы CSS страницы — `rc-`, карточки — `rscene`.

```ts
import { createBot, type Bot } from './bot';
import { CARS, COUNTDOWN, SEG, START_Z, STEP, type CarId } from './config';
import { buildCourse } from './course';
import type { SimEvent } from './events';
import { rng } from './math';
import { createRace, IDLE, ranking, type RaceState } from './state';
import { step, type StepCtx } from './step';

const race = (seed = 7, cars: CarId[] = ['arrow', 'buggy', 'tank']) =>
  createRace(buildCourse(seed), cars.map((car, slot) => ({ slot, car })));

/** Трасса без опасностей: мины, масло и падения убраны, чтобы тест ставил свои. */
function quiet(s: RaceState): RaceState {
  s.course.mines = [];
  s.course.oils = [];
  s.gone = [];
  for (const p of s.course.pylons) p.falls = false;
  return s;
}

function run(s: RaceState, ctx: StepCtx, seconds: number, ev: SimEvent[] = []) {
  const n = Math.round(seconds / STEP);
  for (let i = 0; i < n && !s.over; i++) step(s, STEP, ctx, ev);
  return ev;
}

const idle: StepCtx = { input: () => IDLE, rnd: null, bots: null };

describe('трасса', () => {
  it('из одного зерна — одна и та же трасса', () => {
    expect(JSON.stringify(buildCourse(42))).toBe(JSON.stringify(buildCourse(42)));
    expect(JSON.stringify(buildCourse(43))).not.toBe(JSON.stringify(buildCourse(42)));
  });

  it('мин и масла нет за 34 отрезка до падающей опоры и 22 после', () => {
    for (let seed = 1; seed <= 60; seed++) {
      const c = buildCourse(seed);
      const falls = c.pylons.filter((p) => p.falls);
      for (const h of [...c.mines, ...c.oils]) {
        const seg = Math.round((h.z - 100) / SEG);
        for (const p of falls) expect(p.seg - seg >= 34 || seg - p.seg >= 22).toBe(true);
      }
    }
  });
});

describe('шаг гонки', () => {
  it('до зелёного огня машины стоят', () => {
    const s = race();
    run(s, idle, COUNTDOWN - 0.05);
    for (const c of s.cars) expect(c).toMatchObject({ speed: 0, z: START_Z });
  });

  it('одна и та же гонка из того же зерна и нажатий даёт тот же итог', () => {
    const play = () => {
      const s = race(11);
      const R = rng(5);
      const bots = new Map<number, Bot>([
        [1, createBot(R, s.cars[1].x)],
        [2, createBot(R, s.cars[2].x)],
      ]);
      const ctx: StepCtx = {
        input: (slot) =>
          slot === 0 ? { left: Math.floor(s.t) % 4 === 0, right: Math.floor(s.t) % 4 === 2, brake: false } : IDLE,
        rnd: R,
        bots,
      };
      run(s, ctx, 30);
      return JSON.stringify({ cars: s.cars, gone: s.gone, towers: s.towers, strikes: s.strikes });
    };
    expect(play()).toBe(play());
  });

  it('мина бьёт только хитбоксом: мимо в 0,2 — цел, в 0,15 — удар', () => {
    const miss = quiet(race());
    miss.course.mines = [{ z: START_Z + 3000, x: 0.2, ph: 0 }];
    miss.gone = [false];
    run(miss, idle, COUNTDOWN + 2.5);
    expect(miss.cars[0].hp).toBe(CARS.arrow.hp);
    expect(miss.gone[0]).toBe(false);

    const hit = quiet(race());
    hit.course.mines = [{ z: START_Z + 3000, x: 0.15, ph: 0 }];
    hit.gone = [false];
    const ev = run(hit, idle, COUNTDOWN + 2.5);
    expect(hit.cars[0].hp).toBe(CARS.arrow.hp - 1);
    expect(hit.gone[0]).toBe(true);
    expect(ev).toContainEqual(expect.objectContaining({ k: 'boom', src: 'm0' }));
    expect(ev).toContainEqual(expect.objectContaining({ k: 'hit', slot: 0, dmg: 1, cause: 'mine' }));
  });

  it('удар в неуязвимости крутит машину, но не снимает прочность', () => {
    const s = quiet(race(7, ['tank', 'buggy', 'arrow']));
    s.course.mines = [
      { z: START_Z + 3000, x: 0, ph: 0 },
      { z: START_Z + 3250, x: 0, ph: 0 },
    ];
    s.gone = [false, false];
    const ev = run(s, idle, COUNTDOWN + 4);
    expect(s.gone).toEqual([true, true]);
    expect(s.cars[0].hp).toBe(CARS.tank.hp - 1);
    expect(ev.filter((e) => e.k === 'hit' && e.slot === 0).map((e) => (e as { dmg: number }).dmg)).toEqual([1, 0]);
  });

  it('в лежащую опору врезаются один раз, свободная полоса проезжает', () => {
    const s = quiet(race());
    const i = s.course.pylons.findIndex((p) => p.side > 0 && p.z > START_Z + 1500);
    s.course.pylons[i].falls = true;
    s.towers[i] = 0;
    s.landed[i] = true;
    run(s, idle, COUNTDOWN + 3);
    expect(s.cars[0].hp).toBe(CARS.arrow.hp - 1); // по центру — в опору
    expect(s.cars[1].hp).toBe(CARS.buggy.hp); // слева — свободная полоса

    expect(s.towerHits[i]).toBe(0b101);

    const N = 150;
    const wins: Record<CarId, number> = { arrow: 0, buggy: 0, tank: 0 };
    let allThree = 0;
    let none = 0;
    const order: CarId[] = ['arrow', 'buggy', 'tank'];
    for (let i = 0; i < N; i++) {
      const cars = [order[i % 3], order[(i + 1) % 3], order[(i + 2) % 3]];
      const s = race(1000 + i, cars);
      const R = rng(77 + i);
      const bots = new Map(s.cars.map((c) => [c.slot, createBot(R, c.x)] as const));
      run(s, { input: () => IDLE, rnd: R, bots }, 200);
      const fin = s.cars.filter((c) => c.finished).length;
      if (fin === 3) allThree++;
      if (fin === 0) none++;
      wins[ranking(s.cars)[0].car]++;

    for (const car of order) {
      expect(wins[car] / N).toBeGreaterThan(0.15);
      expect(wins[car] / N).toBeLessThan(0.5);
    }
    expect(allThree / N).toBeLessThan(0.5);
    expect(none / N).toBeLessThan(0.12);
  }, 180_000);
});
```

```ts
/** Помощники симуляции гонки. Файл — в двух копиях, см. `config.ts`. */

export type Rnd = () => number;

export const clamp = (v: number, a: number, b: number): number => (v < a ? a : v > b ? b : v);
export const lerp = (a: number, b: number, t: number): number => a + (b - a) * t;
export const easeInOut = (t: number): number => -Math.cos(t * Math.PI) / 2 + 0.5;

/**
 * mulberry32: одно зерно — одна последовательность на сервере и в браузере.
 * Трасса строится из зерна дважды, и расхождение в одном числе дало бы две
 * разные дороги.
 */
export function rng(seed: number): Rnd {
  let s = seed >>> 0;
  return () => {
    s = (s + 0x6d2b79f5) >>> 0;
    let t = s;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

```ts
import { FIN, LANES, NSEG, SEG, START_SEG, TOWER_LEN, TOWER_X } from './config';
import { clamp, easeInOut, lerp, rng, type Rnd } from './math';

/** Отрезок дороги: кривизна, высота краёв и свет фонаря на нём (0–1). */
export interface Seg {
  curve: number;
  y1: number;
  y2: number;
  pool: number;
}

export interface Lamp {
  z: number;
  side: 1 | -1;
}

/** Опора ЛЭП у обочины. `prev` — номер ближней опоры той же стороны (провода), −1 — нет. */
export interface Pylon {
  seg: number;
  z: number;
  side: 1 | -1;
  /** Упадёт ли за гонку. */
  falls: boolean;
  /** За сколько секунд до подъезда первой машины загорается красная зона. */
  lead: number;
  prev: number;
}

export interface Mine {
  z: number;
  x: number;
  /** Фаза мигания — только для картинки. */
  ph: number;
}

export interface Oil {
  z: number;
  x: number;
  len: number;
  r: number;
}

/** Всё, что выводится из зерна: дорога и расклад опасностей. Не меняется за гонку. */
export interface Course {
  seed: number;
  segs: Seg[];
  lamps: Lamp[];
  pylons: Pylon[];
  mines: Mine[];
  oils: Oil[];
}

function buildSegs(R: Rnd): Seg[] {
  const out: Seg[] = [];
  let y = 0;
  const add = (n: number, curve: number, dy: number) => {
    const y0 = y;
    for (let k = 0; k < n; k++) {
      const t = (k + 0.5) / n;
      const env = Math.min(1, t / 0.3, (1 - t) / 0.3);
      out.push({
        curve: curve * easeInOut(env),
        y1: y0 + dy * easeInOut(k / n),
        y2: y0 + dy * easeInOut((k + 1) / n),
        pool: 0,
      });
    }
    y = y0 + dy;
  };
  add(START_SEG + 26, 0, 0);
  while (out.length < FIN - 70) {
    const n = Math.min(FIN - 70 - out.length, 50 + Math.floor(R() * 80));
    const turn = R() < 0.3 ? 0 : (R() < 0.5 ? -1 : 1) * (1.2 + R() * 2.4);
    const dy = R() < 0.45 ? 0 : (R() * 2 - 1) * 900;
    add(n, turn, dy);
  }
  add(NSEG - out.length, 0, 0);
  return out;
}

/**
 * Трасса из зерна. Порядок вызовов генератора — часть формата: сервер и
 * браузер строят одну и ту же трассу, только пока вызывают его одинаково.
 */
export function buildCourse(seed: number): Course {
  const R = rng(seed);
  const segs = buildSegs(R);

  const lamps: Lamp[] = [];
  for (let i = START_SEG + 2; i < NSEG - 2; i += 8) {
    lamps.push({ z: i * SEG + 100, side: (i / 8) % 2 >= 1 ? 1 : -1 });
    for (let d = -2; d <= 2; d++) {
      const s = segs[i + d];
      if (s) s.pool = Math.max(s.pool, 1 - Math.abs(d) / 2.6);
    }
  }

  const pylons: Pylon[] = [];
  let lastL = -1;
  let lastR = -1;
  for (let i = 14; i < NSEG - 4; i += 20) {
    const side = Math.floor(i / 20) % 2 ? 1 : -1;
    pylons.push({ seg: i, z: i * SEG + 100, side, falls: false, lead: 0, prev: side > 0 ? lastR : lastL });
    if (side > 0) lastR = pylons.length - 1;
    else lastL = pylons.length - 1;
  }
  let lastFall = -999;
  for (const p of pylons) {
    const q = p.seg / FIN;
    if (q < 0.1 || q > 0.95 || p.seg - lastFall < 50) continue;
    if (R() < lerp(0.3, 0.75, q)) {
      p.falls = true;
      p.lead = 1.25 + R() * 0.6;
      lastFall = p.seg;
    }
  }

  // У упавшей опоры свободна одна полоса — мина рядом закрыла бы и её.
  const nearFall = (s: number) => pylons.some((p) => p.falls && p.seg - s < 34 && s - p.seg < 22);
  const mines: Mine[] = [];
  const oils: Oil[] = [];
  const mine = (z: number, x: number) => mines.push({ z, x, ph: R() * 6.28 });
  let s = Math.round(FIN * 0.05);
  for (;;) {
    const q = s / FIN;
    s += Math.round(lerp(44, 18, q) + R() * 14);
    if (s > FIN * 0.97) break;
    if (nearFall(s)) continue;
    const z = s * SEG + 100;
    const r = R();
    if (q > 0.14 && r < 0.12) {
      oils.push({ z, len: 520, x: LANES[Math.floor(R() * 3)] + (R() - 0.5) * 0.2, r: 0.24 });
      continue;
    }
    if (r < 0.45) mine(z, LANES[Math.floor(R() * 3)] + (R() - 0.5) * 0.24);
    else if (r < 0.78) {
      const free = Math.floor(R() * 3);
      for (let l = 0; l < 3; l++) if (l !== free) mine(z + (R() - 0.5) * 60, LANES[l] + (R() - 0.5) * 0.1);
    } else {
      // «Лесенка» через три полосы: тянется на 28 отрезков, и проверять надо все её мины.
      const dir = R() < 0.5;
      if (!nearFall(s + 14) && !nearFall(s + 28))
        for (let k = 0; k < 3; k++) mine(z + k * 14 * SEG, LANES[dir ? k : 2 - k]);
      s += 30;
    }
  }

  return { seed, segs, lamps, pylons, mines, oils };
}

export const segAt = (c: Course, z: number): Seg => c.segs[clamp(Math.floor(z / SEG), 0, NSEG - 1)];

/** Где лежит упавшая опора: от основания за обочиной до верхушки поперёк дороги. */
export function towerSpan(p: Pylon): [number, number] {
  const a = p.side * TOWER_X;
  const b = p.side * (TOWER_X - TOWER_LEN);
  return p.side > 0 ? [b, a + 0.2] : [a - 0.2, b];
}
```

```ts
  if (t < at + WARN_S) return 'warn';
  if (t < at + WARN_S + FALL_S) return 'fall';

}

    if (a.finished && b.finished) return a.finishT - b.finishT;
    if (a.finished !== b.finished) return a.finished ? -1 : 1;
    return b.z - a.z;
  });
}

export function dynOf(s: RaceState): Dyn {
  const { course, ...dyn } = s;
  void course;
  return dyn;
}
```

```ts
import { CAR_HALF, CARS, CENTRI, COUNTDOWN, STRIKE_S, VMAX } from './config';
import { segAt, towerSpan } from './course';
import { clamp, type Rnd } from './math';
import type { CarState, Input, RaceState } from './state';

/**
 * Бот видит только то, что видно игроку: опасность — с её появления на дороге,
 * реагирует с задержкой и иногда не замечает. Состояние бота — только у того,
 * кто его ведёт (сервер, витрина), в снимок оно не входит.
 */
export interface Bot {
  reaction: number;
  miss: number;
  targetX: number;
  timer: number;
  /** Задержка старта: не все трогаются в одно мгновение. */
  wake: number;
  seen: Map<string, number>;
  skip: Set<string>;
}

export function createBot(rnd: Rnd, x: number): Bot {
  return {
    reaction: 0.26 + rnd() * 0.22,
    miss: 0.03 + rnd() * 0.04,
    targetX: x,
    timer: rnd() * 0.1,
    wake: rnd() * 0.3,
    seen: new Map(),
    skip: new Set(),
  };
}

interface Threat {
  t: number;
  a: number;
  b: number;
  w: number;
}

function threats(s: RaceState, car: CarState, bot: Bot, rnd: Rnd): Threat[] {
  const out: Threat[] = [];
  const sp = Math.max(car.speed, 1800);
  const reach = sp * 1.9;
  const c = s.course;
  const add = (key: string, z: number, a: number, b: number, w: number) => {
    const dz = z - car.z;
    if (dz < -260 || dz > reach) return;
    let seen = bot.seen.get(key);
    if (seen === undefined) {
      seen = s.t;
      bot.seen.set(key, s.t);
      if (rnd() < bot.miss) bot.skip.add(key);
    }
    if (bot.skip.has(key) || s.t - seen < bot.reaction) return;
    out.push({ t: Math.max(0, dz) / sp, a, b, w });
  };
  c.mines.forEach((m, i) => {
    if (!s.gone[i]) add('m' + i, m.z, m.x - 0.09, m.x + 0.09, 10);
  });
  c.oils.forEach((o, i) => add('o' + i, o.z + o.len / 2, o.x - o.r, o.x + o.r, 4));
  for (const st of s.strikes) if (s.t >= st.at - STRIKE_S) add('s' + st.id, st.z, st.x - st.r, st.x + st.r, 12);
  c.pylons.forEach((p, i) => {
    const at = s.towers[i];
    if (!p.falls || at === null || s.t < at) return;
    const [a, b] = towerSpan(p);
    add('p' + i, p.z, a, b, 14);
  });
  for (const o of s.cars) if (o.dead && o !== car) add('w' + o.slot, o.z, o.x - CAR_HALF, o.x + CAR_HALF, 9);
  return out;
}

/**
 * Куда рулить: из 21 точки поперёк дороги — та, где сумма опасностей меньше,
 * с учётом того, куда машина успеет доехать к каждой из них.
 */
export function botThink(s: RaceState, car: CarState, bot: Bot, dt: number, rnd: Rnd): Input {
  if (s.t - COUNTDOWN < bot.wake) return { left: false, right: false, brake: true };
  const steer = CARS[car.car].steer;
  bot.timer -= dt;
  if (bot.timer <= 0) {
    bot.timer = 0.08 + rnd() * 0.05;
    const th = threats(s, car, bot, rnd);
    let best = bot.targetX;
    let bestS = Infinity;
    for (let k = -10; k <= 10; k++) {
      const x = k * 0.085;
      let sc = Math.abs(x - car.x) * 0.35 + Math.abs(x) * 0.15 - (Math.abs(x - bot.targetX) < 0.05 ? 0.1 : 0);
      for (const h of th) {
        const reach = steer * Math.max(0, h.t - 0.06);
        const px = car.x + clamp(x - car.x, -reach, reach);
        if (px + CAR_HALF + 0.04 > h.a && px - CAR_HALF - 0.04 < h.b) sc += h.w * (2.2 - Math.min(h.t, 2));
      }
      if (sc < bestS) {
        bestS = sc;
        best = x;
      }
    }
    bot.targetX = best;
  }
  const sp = car.speed / VMAX;
  const want = (bot.targetX - car.x) * 7 + (segAt(s.course, car.z).curve * sp * sp * CENTRI) / steer;
  return { left: false, right: false, brake: false, steer: clamp(want, -1, 1) };
}
```

```ts
import { botThink, type Bot } from './bot';
import {
  AFTER_FIRST,
  ANNOUNCE,
  CAR_HALF,
  CARS,
  CENTRI,
  COUNTDOWN,
  FALL_S,
  HIT,
  STRIKE_S,
  TRACK_LEN,
  VMAX,
  WARN_S,
} from './config';
import { segAt, towerSpan } from './course';
import type { Cause, SimEvent } from './events';
import { clamp, lerp, type Rnd } from './math';
import { progressOf, type CarState, type Input, type RaceState } from './state';

export interface StepCtx {
  /** Нажатия места. У бота не спрашиваются — его ведёт `bots`. */
  input: (slot: number) => Input;
  /** Случайность хода: удары с неба и боты. null — шаг без них (предсказание в браузере). */
  rnd: Rnd | null;
  bots: Map<number, Bot> | null;
}

/**
 * Удар: крутит, отнимает скорость, снимает прочность. В неуязвимости — только
 * крутит (событие с нулём): машину тряхнуло, но второй раз за то же она не платит.
 */
export function hurt(s: RaceState, car: CarState, dmg: number, cause: Cause, ev: SimEvent[]): void {
  if (car.dead || car.finished) return;
  const d = CARS[car.car];
  car.spin = d.stun;
  car.speed *= d.knock;
  car.vx *= 0.3;
  if (car.inv > 0) {
    ev.push({ k: 'hit', t: s.t, slot: car.slot, dmg: 0, cause });
    return;
  }
  car.inv = 1.1;
  car.hp = Math.max(0, car.hp - dmg);
  if (car.hp > 0) {
    ev.push({ k: 'hit', t: s.t, slot: car.slot, dmg, cause });
    return;
  }
  car.dead = true;
  car.deadAt = s.t;
  car.vx = car.x > 0 ? 0.5 : -0.5;
  ev.push({ k: 'boom', t: s.t, z: car.z + 80, x: car.x, big: true, src: 'c' + car.slot });
  ev.push({ k: 'out', t: s.t, slot: car.slot, cause });
}

/** Физика одной машины: газ нажат всегда, тормоз, руль, снос в повороте, отбойник. */
export function driveCar(s: RaceState, car: CarState, dt: number, inp: Input): void {
  const d = CARS[car.car];
  car.inv = Math.max(0, car.inv - dt);
  if (car.dead) {
    car.speed = Math.max(0, car.speed - 4200 * dt);
    car.z += car.speed * dt;
    car.x = clamp(car.x + car.vx * dt, -1.25, 1.25);
    car.vx *= Math.pow(0.1, dt);
    return;
  }
  let steer = inp.steer ?? (inp.right ? 1 : 0) - (inp.left ? 1 : 0);
  if (car.finished) {
    steer = 0;
    car.speed = Math.max(0, car.speed - 1500 * dt);
  } else {
    const max = d.max * (Math.abs(car.x) > 1.02 ? 0.5 : 1);
    if (car.spin > 0) {
      car.spin -= dt;
      steer = 0;
    }
    if (inp.brake) car.speed -= 5600 * dt;
    else if (car.speed < max) car.speed += d.acc * dt * (1 - (0.6 * car.speed) / max);
    if (car.speed > max) car.speed = Math.max(max, car.speed - 5000 * dt);
    if (car.speed < 0) car.speed = 0;
  }
  const slide = car.slide > 0;
  if (slide) car.slide -= dt;
  const want = steer * d.steer * (slide ? 0.25 : 1);
  car.vx += (want - car.vx) * Math.min(1, (slide ? 1.5 : 16) * dt);
  const sp = car.speed / VMAX;
  car.x += car.vx * dt - segAt(s.course, car.z).curve * sp * sp * CENTRI * dt;
  if (car.x > 1.3 || car.x < -1.3) {
    car.x = clamp(car.x, -1.3, 1.3);
    car.vx = 0;
    car.speed *= Math.pow(0.4, dt);
  }
  car.z += car.speed * dt;
}

/**
 * Удары о то, что лежит на дороге: мины, масло, лежащие опоры, обломки. Всё это
 * известно браузеру, поэтому функция общая с его предсказанием.
 */
export function collideCar(s: RaceState, car: CarState, ev: SimEvent[]): void {
  if (car.dead || car.finished) return;
  const c = s.course;
  const bit = 1 << car.slot;
  for (let i = 0; i < c.mines.length; i++) {
    if (s.gone[i]) continue;
    const m = c.mines[i];
    if (Math.abs(car.z - m.z) < 150 && Math.abs(car.x - m.x) < HIT + 0.07) {
      s.gone[i] = true;
      ev.push({ k: 'boom', t: s.t, z: m.z, x: m.x, big: false, src: 'm' + i });
      hurt(s, car, 1, 'mine', ev);
    }
  }
  for (const o of c.oils) {
    if (car.slide > 0 || car.z <= o.z || car.z >= o.z + o.len || Math.abs(car.x - o.x) >= o.r + HIT * 0.5) continue;
    car.slide = 0.85;
    // Несёт прочь от середины лужи: направление — правило, а не жребий, иначе
    // предсказание браузера расходилось бы с сервером на каждой луже.
    car.vx += (car.x >= o.x ? 1 : -1) * 1.8;
    ev.push({ k: 'slide', t: s.t, slot: car.slot });
  }
  for (let i = 0; i < c.pylons.length; i++) {
    if (!s.landed[i] || s.towerHits[i] & bit) continue;
    const p = c.pylons[i];
    if (Math.abs(car.z - p.z) > 130) continue;
    const [a, b] = towerSpan(p);
    if (car.x + HIT > a && car.x - HIT < b) {
      s.towerHits[i] |= bit;
      car.speed *= 0.4;
      hurt(s, car, 1, 'pylon', ev);
    }
  }
  for (const w of s.cars) {
    if (!w.dead || w === car || w.wreckHits & bit) continue;
    if (Math.abs(car.z - w.z) < 260 && Math.abs(car.x - w.x) < HIT * 2) {
      w.wreckHits |= bit;
      car.speed *= 0.55;
      hurt(s, car, 1, 'wreck', ev);
    }
  }
}

function shuffle<T>(a: T[], rnd: Rnd): T[] {
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rnd() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

/** Удар с неба — по очереди на каждую живую машину, туда, где она будет к взрыву. */
function spawnStrike(s: RaceState, rnd: Rnd) {
  if (!s.rr.length) s.rr = shuffle(s.cars.map((c) => c.slot), rnd);
  for (let n = 0; n < s.rr.length; n++) {
    const c = s.cars[s.rr[n]];
    if (c.dead || c.finished || c.z > TRACK_LEN - c.speed * 2.4) continue;
    s.rr.splice(n, 1);
    const lead = ANNOUNCE + STRIKE_S;
    s.strikes.push({
      id: ++s.strikeSeq,
      z: c.z + Math.max(c.speed, 2500) * lead * (0.92 + rnd() * 0.16),
      x: clamp(c.x + (rnd() - 0.5) * 0.25, -0.85, 0.85),
      r: 0.3,
      at: s.t + lead,
      target: c.slot,
    });
    return;
  }
}

/** Чем ближе лидер к финишу, тем чаще удары. */
function schedule(s: RaceState, rnd: Rnd) {
  if (s.t < s.nextStrike) return;
  const alive = s.cars.filter((c) => !c.dead);
  const lead = alive.length ? Math.max(...alive.map(progressOf)) : 0;
  if (lead > 0.2) spawnStrike(s, rnd);
  s.nextStrike = s.t + lerp(4.4, 2.3, clamp((lead - 0.2) / 0.8, 0, 1)) + rnd() * 1.2;
}

/** Один шаг гонки. Время — первым: всё, что шаг пишет в события, помечено концом шага. */
export function step(s: RaceState, dt: number, ctx: StepCtx, ev: SimEvent[]): void {
  if (s.over) return;
  s.t += dt;
  if (s.t < COUNTDOWN) return;
  const c = s.course;

  for (const car of s.cars) {
    const bot = ctx.bots?.get(car.slot);
    const inp =
      bot && ctx.rnd && !car.dead && !car.finished ? botThink(s, car, bot, dt, ctx.rnd) : ctx.input(car.slot);
    driveCar(s, car, dt, inp);
  }

  // Машины друг друга не ломают — только расталкивают.
  for (let i = 0; i < s.cars.length; i++)
    for (let j = i + 1; j < s.cars.length; j++) {
      const a = s.cars[i];
      const b = s.cars[j];
      if (a.dead || b.dead || a.finished || b.finished) continue;
      const gap = Math.abs(a.x - b.x);
      if (Math.abs(a.z - b.z) >= 360 || gap >= CAR_HALF * 2) continue;
      const push = (CAR_HALF * 2 - gap) / 2 + 0.002;
      const dir = a.x < b.x ? -1 : 1;
      a.x += dir * push;
      b.x -= dir * push;
      a.vx += dir * 0.4;
      b.vx -= dir * 0.4;
      (a.z < b.z ? a : b).speed *= 0.992;
    }

  // Опоры: красная зона — за `lead` до подъезда первой машины, объявлена на ANNOUNCE вперёд.
  for (let i = 0; i < c.pylons.length; i++) {
    const p = c.pylons[i];
    if (!p.falls || s.landed[i]) continue;
    const at = s.towers[i];
    if (at === null) {
      for (const car of s.cars) {
        if (car.dead || car.finished) continue;
        const dz = p.z - car.z;
        if (dz > 0 && dz / Math.max(car.speed, 1800) < p.lead + ANNOUNCE) {
          s.towers[i] = s.t + ANNOUNCE;
          break;
        }
      }
      continue;
    }
    if (s.t < at + WARN_S + FALL_S) continue;
    s.landed[i] = true;
    ev.push({ k: 'land', t: s.t, pylon: i });
    const [a, b] = towerSpan(p);
    for (const car of s.cars) {
      if (car.dead || car.finished) continue;
      if (Math.abs(car.z - p.z) < 260 && car.x + HIT > a && car.x - HIT < b) {
        s.towerHits[i] |= 1 << car.slot;
        hurt(s, car, 2, 'pylon', ev);
      }
    }
  }

  if (s.strikes.length) {
    const left = [];
    for (const st of s.strikes) {
      if (s.t < st.at) {
        left.push(st);
        continue;
      }
      ev.push({ k: 'boom', t: s.t, z: st.z, x: st.x, big: true, src: 's' + st.id });
      for (const car of s.cars)
        if (!car.dead && !car.finished && Math.abs(car.z - st.z) < 300 && Math.abs(car.x - st.x) < st.r + HIT)
          hurt(s, car, 2, 'strike', ev);
    }
    s.strikes = left;
  }

  for (const car of s.cars) collideCar(s, car, ev);
  if (ctx.rnd) schedule(s, ctx.rnd);

  for (const car of s.cars) {
    if (car.finished || car.dead || car.z < TRACK_LEN) continue;
    car.finished = true;
    car.finishT = s.t - COUNTDOWN;
    const first = s.firstFinT === null;
    if (first) s.firstFinT = s.t;
    ev.push({ k: 'finish', t: s.t, slot: car.slot, first });
  }

  if (s.overAt === null) {
    if (s.cars.every((x) => x.dead || x.finished)) s.overAt = s.t + 2.2;
    else if (s.firstFinT !== null && s.t - s.firstFinT > AFTER_FIRST) s.overAt = s.t;
  }
  if (s.overAt !== null && s.t >= s.overAt) s.over = true;
}
```

```ts
import { DELAY_MS, STUCK_S } from './race.config';
import {
  buildCourse,
  createBot,
  createRace,
  IDLE,
  rng,
  step,
  STEP,
  type Bot,
  type CarId,
  type Input,
  type RaceState,
  type Rnd,
  type SimEvent,
  type StepCtx,
} from './sim';

export interface RacerSpec {
  slot: number;
  car: CarId;
  bot: boolean;
}

/**
 * Одна идущая гонка: симуляция, нажатия по времени и события для снимка.
 * Без Nest, базы и таймеров — часы передаются вызовом, поэтому её можно
 * гонять в тестах точно.
 *
 * Симуляция идёт на `DELAY_MS` позади часов: нажатие, дошедшее быстрее,
 * ложится на свой момент; опоздавшее действует с момента прихода — прошлое
 * не переписывается.
 */
export class RaceRuntime {
  readonly state: RaceState;
  private readonly rnd: Rnd;
  private readonly bots = new Map<number, Bot>();
  private readonly pending = new Map<number, { t: number; input: Input }[]>();
  private readonly current = new Map<number, Input>();
  private readonly heard = new Map<number, number>();
  private events: SimEvent[] = [];
  private readonly ctx: StepCtx;

  constructor(
    readonly startAt: number,
    seed: number,
    racers: RacerSpec[],
    runSeed: number,
  ) {
    this.state = createRace(
      buildCourse(seed),
      racers.map(({ slot, car }) => ({ slot, car })),
    );
    this.rnd = rng(runSeed);
    for (const r of racers) if (r.bot) this.bots.set(r.slot, createBot(this.rnd, this.state.cars[r.slot].x));
    this.ctx = { input: (slot) => this.inputOf(slot), rnd: this.rnd, bots: this.bots };
  }

  /** Время гонки по часам сервера, с. */
  clock(nowMs: number): number {
    return (nowMs - this.startAt) / 1000;
  }

  push(slot: number, t: number, input: Input, nowMs: number): void {
    if (this.bots.has(slot) || !Number.isFinite(t)) return;
    const now = this.clock(nowMs);
    this.heard.set(slot, now);
    const when = Math.min(Math.max(t, this.state.t), now);
    const q = this.pending.get(slot) ?? [];
    q.push({ t: when, input });
    q.sort((a, b) => a.t - b.t);
    this.pending.set(slot, q);
  }

  advance(nowMs: number): void {
    const target = this.clock(nowMs) - DELAY_MS / 1000;
    while (!this.state.over && this.state.t + STEP <= target + 1e-9) {
      for (const [slot, q] of this.pending) {
        while (q.length && q[0].t <= this.state.t + 1e-9) this.current.set(slot, q.shift()!.input);
      }
      step(this.state, STEP, this.ctx, this.events);
    }
  }

  drain(): SimEvent[] {
    const out = this.events;
    this.events = [];
    return out;
  }

  private inputOf(slot: number): Input {
    const heard = this.heard.get(slot);
    if (heard === undefined || this.state.t - heard > STUCK_S) return IDLE;
    return this.current.get(slot) ?? IDLE;
  }
}
```

```ts
import type { RaceRuntime } from './race-runtime';
import { COUNTDOWN, dynOf, type CarId, type Dyn, type SimEvent } from './sim';

export interface Entry {
  /** id строки `RaceEntry`; у бота до старта строки нет — пусто. */
  entryId: string;
  slot: number;
  userId: string | null;
  name: string | null;
  car: CarId;
  joinedAt: Date;
  bot: boolean;
}

export interface ResultRow {
  slot: number;
  place: number;
  finishMs: number | null;
  progress: number;
  payout: number;
}

/** Гонка в памяти процесса игр — от открытия лобби до забвения итога. */
export interface RaceRecord {
  id: string;
  stake: number;
  seed: number;
  createdAt: number;
  lobbyEndsAt: number;
  entries: Entry[];
  runtime: RaceRuntime | null;
  result: ResultRow[] | null;
  finishing: boolean;
  closed: boolean;
}

export type RacePhase = 'none' | 'lobby' | 'countdown' | 'racing' | 'over';

/** Снимок гонки. Тайного в гонке нет — каждому одно и то же, кроме пометки «я». */
export interface RaceWire {
  phase: RacePhase;
  serverNow: number;
  config: { stakes: number[]; waitMs: number; delayMs: number };
  race: null | {
    id: string;
    stake: number;
    pot: number;
    seed: number;
    lobbyEndsAt: number;
    /** Время сервера, когда загорелся первый красный огонь; до старта — null. */
    startAt: number | null;
    racers: { slot: number; name: string | null; bot: boolean; car: CarId; me: boolean }[];
    me: number | null;
    dyn: Dyn | null;
    events: SimEvent[];
    result: ResultRow[] | null;
  };
}

export function phaseOf(rec: RaceRecord | null): RacePhase {
  if (!rec) return 'none';
  if (rec.result) return 'over';
  if (!rec.runtime) return 'lobby';
  return rec.runtime.state.t < COUNTDOWN ? 'countdown' : 'racing';
}

export function buildView(rec: RaceRecord | null, userId: string, now: number, events: SimEvent[]): RaceWire {
  const config = { stakes: STAKES, waitMs: WAIT_MS, delayMs: DELAY_MS };
  if (!rec) return { phase: 'none', serverNow: now, config, race: null };
  const me = rec.entries.find((e) => e.userId === userId)?.slot ?? null;
  return {
    phase: phaseOf(rec),
    serverNow: now,
    config,
    race: {
      id: rec.id,
      stake: rec.stake,
      pot: rec.stake * 3,
      seed: rec.seed,
      lobbyEndsAt: rec.lobbyEndsAt,
      startAt: rec.runtime?.startAt ?? null,
      racers: rec.entries.map((e) => ({ slot: e.slot, name: e.name, bot: e.bot, car: e.car, me: e.slot === me })),
      me,
      dyn: rec.runtime ? dynOf(rec.runtime.state) : null,
      events,
      result: rec.result,
    },
  };
}
```

```ts
/**

 * Всё в памяти процесса игр (`ROLE=games`, он один) — как раздачи и раунд
 * джетпака; деньги — транзакциями. Спека — `2026-10-18-race-game-design.md`.
 *
 * Лобби, старт, выход и финиш — через одну очередь (`exclusive`): вход и
 * таймер ботов не должны разойтись на одном месте. Такт симуляции идёт мимо
 * очереди — он трогает только память.
 */
@Injectable()
export class RaceService implements OnModuleInit, OnApplicationBootstrap, OnModuleDestroy {
  private readonly logger = new Logger(RaceService.name);
  private queue: Promise<unknown> = Promise.resolve();
  /** Собирающаяся гонка ставки. */
  private readonly lobbies = new Map<number, RaceRecord>();
  /** Все гонки в памяти: лобби, идущие и законченные, пока помнится итог. */
  private readonly races = new Map<string, RaceRecord>();
  /** Где человек сейчас: лобби или идущая гонка. */
  private readonly seatOf = new Map<string, string>();
  /** Последняя законченная гонка человека — для итога на странице. */
  private readonly lastOf = new Map<string, string>();
  private readonly timers = new Set<NodeJS.Timeout>();
  private readonly rate = new Map<string, { sec: number; n: number }>();
  private loop: NodeJS.Timeout | null = null;

  /** Зерно — криптослучайное; тесты подменяют. */
  seed: () => number = () => randomInt(0, 2 ** 31 - 1);

  constructor(
    private readonly prisma: PrismaService,
    private readonly coins: CoinsService,
    private readonly gateway: GamesGateway,
    private readonly battlePass: BattlePassService,
  ) {}

  onModuleInit() {
    this.gateway.listen('race_input', (userId, payload) => this.input(userId, payload));
  }

  /**
   * Гонка без `finishedAt` при старте процесса — прервана перезапуском (лобби
   * тоже): живым возвращаются взносы. Банк теряется, деньги — нет.
   */
  async onApplicationBootstrap() {
    let open: { id: string; stake: number; entries: { userId: string | null; joinedAt: Date }[] }[];
    try {
      open = await this.prisma.raceRound.findMany({
        where: { finishedAt: null },
        select: { id: true, stake: true, entries: { select: { userId: true, joinedAt: true } } },
      });
    } catch (e) {
      this.logger.error(`interrupted races: ${(e as Error).message}`);
      return;
    }
    for (const r of open) {
      try {
        await this.prisma.$transaction(async (tx) => {
          const moved = await tx.raceRound.updateMany({
            where: { id: r.id, finishedAt: null },
            data: { finishedAt: new Date(), voided: true },
          });
          if (moved.count === 0) return;
          for (const e of r.entries)
            if (e.userId) await this.coins.credit(tx, e.userId, r.stake, 'RACE_REFUND', refOf(r.id, e.joinedAt));
        });
      } catch (e) {
        this.logger.error(`void race ${r.id}: ${(e as Error).message}`);
      }
    }
  }

  onModuleDestroy() {
    for (const t of this.timers) clearTimeout(t);
    this.timers.clear();
    if (this.loop) clearInterval(this.loop);
    this.loop = null;
  }

  // ── очередь и таймеры ─────────────────────────────────────────

  private exclusive<T>(fn: () => Promise<T>): Promise<T> {
    const run = this.queue.then(fn);
    this.queue = run.catch(() => undefined);
    return run;
  }

  private log(what: string) {
    return (e: Error) => this.logger.error(`${what}: ${e.message}`);
  }

  private later(ms: number, fn: () => Promise<void>) {
    const t = setTimeout(() => {
      this.timers.delete(t);
      void this.exclusive(fn).catch(this.log('timer'));
    }, ms);
    this.timers.add(t);
  }

  private emit(rec: RaceRecord, events: SimEvent[]) {
    const now = Date.now();
    void this.gateway
      .emitPersonal(ROOM_PREFIX + rec.id, 'race_state', (userId) => buildView(rec, userId, now, events))
      .catch(this.log('emit'));
  }

  // ── действия игрока ───────────────────────────────────────────

  view(userId: string): RaceWire {
    const id = this.seatOf.get(userId) ?? this.lastOf.get(userId);
    return buildView((id && this.races.get(id)) || null, userId, Date.now(), []);
  }

  join(userId: string, stake: number, car: string): Promise<RaceWire> {
    return this.exclusive(async () => {
      if (!STAKES.includes(stake)) throw raceBadStake();
      if (!(CAR_IDS as readonly string[]).includes(car)) throw raceBadCar();
      if (this.seatOf.has(userId)) throw raceAlreadyIn();

      // Строка гонки создаётся той же транзакцией, что и взнос: отказ в монетах
      // не оставляет пустого лобби.
      const open = this.lobbies.get(stake);
      const id = open?.id ?? randomUUID();
      const seed = open?.seed ?? this.seed();
      const slot = [0, 1, 2].find((s) => !open?.entries.some((e) => e.slot === s))!;
      const joinedAt = new Date();
      const row = await this.prisma.$transaction(async (tx) => {
        if (!open) await tx.raceRound.create({ data: { id, stake, seed } });
        await this.coins.charge(tx, userId, stake, 'RACE_STAKE', refOf(id, joinedAt));
        return tx.raceEntry.create({
          data: { raceId: id, userId, slot, car, joinedAt },
          select: { id: true, user: { select: { name: true } } },
        });
      });

      let rec = open;
      if (!rec) {
        const now = Date.now();
        rec = {
          id,
          stake,
          seed,
          createdAt: now,
          lobbyEndsAt: now + WAIT_MS,
          entries: [],
          runtime: null,
          result: null,
          finishing: false,
          closed: false,
        };
        this.lobbies.set(stake, rec);
        this.races.set(id, rec);
        const opened = rec;
        this.later(WAIT_MS, () => this.start(opened));
      }
      rec.entries.push({ entryId: row.id, slot, userId, name: row.user?.name ?? null, car: car as CarId, joinedAt, bot: false });
      rec.entries.sort((a, b) => a.slot - b.slot);
      this.seatOf.set(userId, id);
      this.lastOf.delete(userId);
      if (rec.entries.length === 3) await this.start(rec);
      else this.emit(rec, []);
      return buildView(rec, userId, Date.now(), []);
    });
  }

  leave(userId: string): Promise<RaceWire> {
    return this.exclusive(async () => {
      const id = this.seatOf.get(userId);
      const rec = id ? this.races.get(id) : undefined;
      if (!rec) throw raceNotIn();
      if (rec.runtime) throw raceStarted();
      const entry = rec.entries.find((e) => e.userId === userId)!;
      const last = rec.entries.length === 1;
      await this.prisma.$transaction(async (tx) => {
        await tx.raceEntry.delete({ where: { id: entry.entryId } });
        await this.coins.credit(tx, userId, rec.stake, 'RACE_REFUND', refOf(rec.id, entry.joinedAt));
        if (last) await tx.raceRound.delete({ where: { id: rec.id } });
      });
      rec.entries = rec.entries.filter((e) => e !== entry);
      this.seatOf.delete(userId);
      if (last) {
        rec.closed = true;
        this.lobbies.delete(rec.stake);
        this.races.delete(rec.id);
      } else this.emit(rec, []);
      return buildView(null, userId, Date.now(), []);
    });
  }

  /**
   * Нажатия из сокета: `{ raceId, t, l, r, b }`. Чужая гонка, кривая форма и
   * больше `INPUT_RATE` в секунду — мимо: это руль, а не деньги, и отказ ему
   * не нужен.
   */
  input(userId: string, payload: unknown) {
    if (!payload || typeof payload !== 'object') return;
    const p = payload as Record<string, unknown>;
    const id = this.seatOf.get(userId);
    if (!id || p.raceId !== id || typeof p.t !== 'number') return;
    const rec = this.races.get(id);
    const rt = rec?.runtime;
    if (!rec || !rt || rec.result) return;
    const now = Date.now();
    const sec = Math.floor(now / 1000);
    const r = this.rate.get(userId);
    if (r && r.sec === sec) {
      if (++r.n > INPUT_RATE) return;
    } else this.rate.set(userId, { sec, n: 1 });
    const slot = rec.entries.find((e) => e.userId === userId)?.slot;
    if (slot === undefined) return;
    rt.push(slot, p.t, { left: p.l === true, right: p.r === true, brake: p.b === true }, now);
  }

  // ── жизнь гонки ───────────────────────────────────────────────

  /** Старт: пустые места — ботам, строка гонки и опыт живым — одной транзакцией. */
  private async start(rec: RaceRecord) {
    if (rec.closed || rec.runtime) return;
    const humans = rec.entries.filter((e) => !e.bot);
    if (!humans.length) return;
    const names = [...BOT_NAMES].sort(() => Math.random() - 0.5);
    const free = [0, 1, 2].filter((s) => !rec.entries.some((e) => e.slot === s));
    const joinedAt = new Date();
    const bots: Entry[] = free.map((slot, i) => ({
      entryId: '',
      slot,
      userId: null,
      name: names[i],
      car: CAR_IDS[randomInt(CAR_IDS.length)],
      joinedAt,
      bot: true,
    }));
    try {
      await this.prisma.$transaction(async (tx) => {
        await tx.raceRound.updateMany({ where: { id: rec.id, startedAt: null }, data: { startedAt: new Date() } });
        if (bots.length)
          await tx.raceEntry.createMany({
            data: bots.map((b) => ({ raceId: rec.id, userId: null, botName: b.name, slot: b.slot, car: b.car, joinedAt })),
          });
        for (const h of humans) await this.battlePass.award(tx, h.userId!, 'game.race', rec.id, XP_SOURCES['game.race'].base);
      });
    } catch (e) {
      this.logger.error(`start race ${rec.id}: ${(e as Error).message}`);
      this.later(RETRY_MS, () => this.start(rec));
      return;
    }
    rec.entries = [...rec.entries, ...bots].sort((a, b) => a.slot - b.slot);
    this.lobbies.delete(rec.stake);
    rec.runtime = new RaceRuntime(
      Date.now(),
      rec.seed,
      rec.entries.map((e) => ({ slot: e.slot, car: e.car, bot: e.bot })),
      this.seed(),
    );
    this.emit(rec, []);
    if (!this.loop) this.loop = setInterval(() => this.tick(), TICK_MS);
  }

  /** Такт: догнать симуляцию, разослать снимок, закончившуюся — к финишу. */
  private tick() {
    const now = Date.now();
    let running = 0;
    for (const rec of this.races.values()) {
      const rt = rec.runtime;
      if (!rt || rec.result) continue;
      running++;
      rt.advance(now);
      this.emit(rec, rt.drain());
      if (rt.state.over && !rec.finishing) {
        rec.finishing = true;
        void this.exclusive(() => this.finish(rec)).catch(this.log('finish'));
      }
    }
    if (!running && this.loop) {
      clearInterval(this.loop);
      this.loop = null;
    }
  }

  /**
   * Финиш: места и выплата — одной транзакцией, условным `updateMany` по
   * `finishedAt: null`: второй финиш той же гонки ничего не найдёт и не заплатит.
   * Выигрыш бота сгорает — он играет за заведение.
   */
  private async finish(rec: RaceRecord) {
    const rt = rec.runtime!;
    const order = ranking(rt.state.cars);
    const pot = rec.stake * 3;
    const winner = rec.entries[order[0].slot];
    const rows: ResultRow[] = order.map((c, i) => ({
      slot: c.slot,
      place: i + 1,
      finishMs: c.finished ? Math.round(c.finishT * 1000) : null,
      progress: progressOf(c),
      payout: i === 0 && !winner.bot ? pot : 0,
    }));
    try {
      await this.prisma.$transaction(async (tx) => {
        const done = await tx.raceRound.updateMany({
          where: { id: rec.id, finishedAt: null },
          data: { finishedAt: new Date() },
        });
        if (done.count === 0) return;
        for (const r of rows)
          await tx.raceEntry.updateMany({
            where: { raceId: rec.id, slot: r.slot },
            data: { place: r.place, finishMs: r.finishMs, progress: r.progress, payout: r.payout },
          });
        if (!winner.bot) await this.coins.credit(tx, winner.userId!, pot, 'RACE_WIN', rec.id);
      });
    } catch (e) {
      this.logger.error(`finish race ${rec.id}: ${(e as Error).message}`);
      this.later(RETRY_MS, () => this.finish(rec));
      return;
    }
    rec.result = rows;
    for (const e of rec.entries) {
      if (!e.userId) continue;
      this.seatOf.delete(e.userId);
      this.lastOf.set(e.userId, rec.id);
      this.rate.delete(e.userId);
    }
    this.emit(rec, rt.drain());
    this.later(RESULT_KEEP_MS, async () => {
      this.races.delete(rec.id);
      for (const e of rec.entries) if (e.userId && this.lastOf.get(e.userId) === rec.id) this.lastOf.delete(e.userId);
    });
  }
}

/** Ключ журнала монет участия: вход и выход в ту же гонку — два участия, как у турнира. */
const refOf = (raceId: string, joinedAt: Date) => `${raceId}:${joinedAt.getTime()}`;
```

```ts
/** Вид с сервера (`backend/src/race/race-view.ts`). */
export type RacePhase = 'none' | 'lobby' | 'countdown' | 'racing' | 'over';

export interface RaceRacer {
  slot: number;
  name: string | null;
  bot: boolean;
  car: CarId;
  me: boolean;
}

export interface RaceResultRow {
  slot: number;
  place: number;
  finishMs: number | null;
  progress: number;
  payout: number;
}

export interface RaceInfo {
  id: string;
  stake: number;
  pot: number;
  seed: number;
  lobbyEndsAt: number;
  startAt: number | null;
  racers: RaceRacer[];
  me: number | null;
  dyn: Dyn | null;
  events: SimEvent[];
  result: RaceResultRow[] | null;
}

export interface RaceConfig {
  stakes: number[];
  waitMs: number;
  delayMs: number;
}

export interface RaceWire {
  phase: RacePhase;
  serverNow: number;
  config: RaceConfig;
  race: RaceInfo | null;
}
```

```ts
import type { RaceView } from '../api/types';
import {
  collideCar,
  COUNTDOWN,
  driveCar,
  IDLE,
  lerp,
  STEP,
  type CarState,
  type Course,
  type Dyn,
  type Input,
  type RaceState,
  type SimEvent,
} from './sim';

/** Время гонки по часам сервера, с: `Date.now() + offset` — серверное время. */
export function raceClock(v: RaceView, nowMs = Date.now()): number {
  const startAt = v.race?.startAt;
  return startAt == null ? 0 : (nowMs + v.offset - startAt) / 1000;
}

/** Нажатия своей машины по времени гонки — для предсказания. */
export class InputLog {
  private marks: { t: number; input: Input }[] = [];

  push(t: number, input: Input) {
    const last = this.marks[this.marks.length - 1];
    this.marks.push({ t: last && last.t > t ? last.t : t, input });
  }

  at(t: number): Input {
    for (let i = this.marks.length - 1; i >= 0; i--) if (this.marks[i].t <= t + 1e-9) return this.marks[i].input;
    return IDLE;
  }

  /** Старое — прочь, но нажатие, действующее на `before`, остаётся. */
  prune(before: number) {
    let k = 0;
    while (k + 1 < this.marks.length && this.marks[k + 1].t <= before) k++;
    if (k) this.marks.splice(0, k);
  }
}

/**
 * Своя машина вперёд от снимка той же физикой, что у сервера, и в том же
 * порядке: нажатие берётся на начало шага, время — первым. Удары о лежащее на
 * дороге тоже предсказываются (взрыв мины — сразу), а прочность и выбывание —
 * нет: их решает сервер, и машина в предсказании не умирает.
 */
export function predictCar(
  course: Course,
  dyn: Dyn,
  slot: number,
  log: InputLog,
  toT: number,
  ev: SimEvent[],
): { car: CarState; gone: boolean[] } {
  const own = dyn.cars[slot];
  const s: RaceState = {
    ...dyn,
    course,
    cars: dyn.cars.map((c) => ({ ...c })),
    gone: [...dyn.gone],
    towerHits: [...dyn.towerHits],
    strikes: [],
  };
  const car = s.cars[slot];
  if (own.dead || own.finished) return { car, gone: s.gone };
  car.hp = 99;
  let t = dyn.t;
  // Не дальше 2,5 с вперёд: снимок старше — это обрыв связи, а не задержка.
  for (let n = 0; n < 150 && t + STEP <= toT + 1e-9; n++) {
    const inp = log.at(t);
    t += STEP;
    s.t = t;
    if (t < COUNTDOWN) continue;
    driveCar(s, car, STEP, inp);
    collideCar(s, car, ev);
  }
  car.hp = own.hp;
  return { car, gone: s.gone };
}

export interface Snap {
  t: number;
  cars: CarState[];
}

/** Чужие машины — между двумя снимками по времени гонки; позже последнего — последний. */
export function interpCars(snaps: Snap[], t: number): CarState[] | null {
  if (!snaps.length) return null;
  const i = snaps.findIndex((s) => s.t > t);
  if (i === -1) return snaps[snaps.length - 1].cars;
  if (i === 0) return snaps[0].cars;
  const a = snaps[i - 1];
  const b = snaps[i];
  const u = (t - a.t) / (b.t - a.t);
  return b.cars.map((cb, k) => {
    const ca = a.cars[k];
    return { ...cb, x: lerp(ca.x, cb.x, u), z: lerp(ca.z, cb.z, u), speed: lerp(ca.speed, cb.speed, u), vx: lerp(ca.vx, cb.vx, u) };
  });
}

/**
 * Снимки гонки мимо React: сокет приносит их 20 раз в секунду, и класть каждый
 * в кэш значило бы перерисовывать страницу на каждом. Сцена читает отсюда
 * сама; в кэш react-query уходит только то, что меняет разметку.
 */
export class LiveStore {
  view: RaceView | null = null;
  snaps: Snap[] = [];
  private queue: SimEvent[] = [];
  private lastT = -1;

  push(v: RaceView) {
    const same = this.view?.race?.id === v.race?.id;
    if (same && this.view && this.view.serverNow > v.serverNow) return;
    if (!same) {
      this.snaps = [];
      this.queue = [];
      this.lastT = -1;
    }
    this.view = v;
    const d = v.race?.dyn;
    if (!d || d.t <= this.lastT) return;
    this.lastT = d.t;
    this.snaps.push({ t: d.t, cars: d.cars });
    while (this.snaps.length > 2 && this.snaps[1].t < d.t - 1.5) this.snaps.shift();
    this.queue.push(...v.race!.events);
  }

  /** События, чьё время наступило на шкале чужих машин. */
  take(until: number): SimEvent[] {
    const out: SimEvent[] = [];
    const rest: SimEvent[] = [];
    for (const e of this.queue) (e.t <= until ? out : rest).push(e);
    this.queue = rest;
    return out;
  }
}
```

```ts
};

export const useRaceLeave = () => {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: () => apiJson<RaceWire>('/api/games/race/leave', { method: 'POST' }),
    onSuccess: (w) => put(qc, w),

/**
 * Сокет гонки: комната `race:<id>`. Каждый снимок — в `store` (его читает
 * сцена), в кэш — только смена разметки. На (пере)подключение — свежий REST.
 * Возвращает отправку нажатий: `t` — время гонки, когда нажали.
 */
export function useRaceSocket(raceId: string | null, store: LiveStore) {
  const qc = useQueryClient();
  const sock = useRef<Socket | null>(null);
  useEffect(() => {
    if (!raceId) return;
    const room = `race:${raceId}`;
    const socket = openGamesSocket(room, () => void qc.invalidateQueries({ queryKey: raceKey }));
    socket.on('race_state', (w: RaceWire) => {
      const v = stamp(w);
      store.push(v);
      const old = qc.getQueryData<RaceView>(raceKey);
      if (shape(old) !== shape(v)) qc.setQueryData<RaceView>(raceKey, (o) => newer(o, v));
      if (v.phase === 'over' && old?.phase !== 'over') void qc.invalidateQueries({ queryKey: ['coins'] });
    });
    sock.current = socket;
    return () => {
      sock.current = null;
      closeGamesSocket(socket, room);
    };
  }, [raceId, qc, store]);

  return useCallback(
    (t: number, input: Input) => {
      sock.current?.emit('race_input', { raceId, t, l: input.left, r: input.right, b: input.brake });
    },
    [raceId],
  );
}
```

```ts
function buildBackdrop(ctx: CanvasRenderingContext2D, w: number, h: number, hy: number): Backdrop {
  const R = rng(11);

  const cx1 = new Float64Array(NSEG);
  const cx2 = new Float64Array(NSEG);
  const clipY = new Float64Array(NSEG);
  let bd: Backdrop | null = null;
  let course: Course | null = null;
  let parts: Part[] = [];
  let rings: Ring[] = [];
  let scorches: Mark[] = [];

  let camLat = 0;

  function resize(w: number, h: number, dpr: number) {
    canvas.width = Math.round(w * dpr);
    canvas.height = Math.round(h * dpr);
    // Машина стоит на hy + k·h: в ширину — на 0,85 высоты, в вертикальном кадре выше.
    const wide = w > h;
    view.w = w;
    view.h = h;
    view.dpr = dpr;
    view.hy = h * (wide ? 0.4 : 0.3);
    const k = wide ? 0.45 : 0.4;
    const roadPx = wide ? 0.62 * w : 0.95 * w;

    view.f = (view.dp * k * h) / view.camH;

  function proj(z: number, xn: number, yw = 0): P | null {
    const i = Math.floor(z / SEG);
    if (i < cam.base || i >= cam.end) return null;
    const dz = z - cam.z;
    if (dz < 50) return null;
    const s = course!.segs[i];
    const t = (z - i * SEG) / SEG;
    const k = view.f / dz;
    return {
      X: view.w / 2 + (lerp(cx1[i], cx2[i], t) + xn * HALF - cam.x) * k,
      Y: view.hy + (cam.y - lerp(s.y1, s.y2, t) - yw) * k,
      k,
      clip: clipY[i],

  /** События кадра и то, что выводится из времени: взрыв прицела, легла опора. */
  function applyEvents(f: Frame) {
    for (const e of f.events) {
      if (e.k === 'boom') {

      } else if (e.k === 'hit') {

      if (p.falls && !fired.has('p' + i) && towerPhase(f.towers[i], f.t) === 'down') landDust(i, f);
    });

  function stepFx(dt: number, f: Frame) {
    for (let i = parts.length - 1; i >= 0; i--) {
      const p = parts[i];
      p.life += dt;
      if (p.life >= p.max) {
        parts[i] = parts[parts.length - 1];
        parts.pop();
        continue;
      }
      p.z += p.vz * dt;
      p.x += p.vx * dt;
      p.y += p.vy * dt;
      if (p.k === 'spark' || p.k === 'debris') {
        p.vy -= 2800 * dt;
        if (p.y < 0) {
          p.y = 0;
          p.vy *= -0.3;
          p.vz *= 0.6;
          p.vx *= 0.6;
        }
      } else {
        const drag = p.k === 'fire' ? 0.3 : 0.55;
        p.vy *= Math.pow(p.k === 'fire' ? 0.35 : 0.65, dt);
        p.vz *= Math.pow(drag, dt);
        p.vx *= Math.pow(drag, dt);
      }

    if (parts.length > 800) parts.splice(0, parts.length - 800);
    for (const g of rings) g.t += dt;
    rings = rings.filter((g) => g.t < g.max);

      if (towerPhase(f.towers[i], f.t) === 'warn' && Math.random() < 0.35) sparks(p.z, p.side * TOWER_X, 1, 30);
    });
    // Обломки горят 8 с и дымят 14.
    for (const c of f.cars) {
      if (!c.dead) continue;
      emitIn[c.slot] -= dt;
      if (emitIn[c.slot] > 0) continue;
      emitIn[c.slot] = 0.05;
      const age = f.t - c.deadAt;
      const R = Math.random;
      if (age < 8)
        puff('fire', c.z + R() * 60, c.x + (R() - 0.5) * 0.1, 50 + R() * 50, { vx: (R() - 0.5) * 0.1, vy: 300 + R() * 400, max: 0.35 + R() * 0.3, size: 55 + R() * 45 });
      if (age < 14)
        puff('smoke', c.z, c.x + (R() - 0.5) * 0.08, 150, { vx: (R() - 0.5) * 0.08, vy: 350 + R() * 200, max: 2 + R(), size: 110 + R() * 60 });
    }
    shake *= Math.pow(0.015, dt);
    flash *= Math.pow(0.004, dt);
    fade *= Math.pow(0.02, dt);

  function drawSeg(i: number, X1: number, Y1: number, R1: number, X2: number, Y2: number, R2: number, dz: number) {
    const s = course!.segs[i];
    const fog = fogAt(dz);
    const alt = Math.floor(i / 3) % 2;
    let gc = alt ? GROUND_A : GROUND_B;
    if (s.pool) gc = mix(gc, GROUND_LIT, s.pool * 0.5);
    G.fillStyle = rgb(mix(gc, FOG, fog));
    G.fillRect(-30, Y2, view.w + 60, Math.min(Y1, view.h + 30) - Y2 + 1);
    G.fillStyle = rgb(mix(Math.floor(i / 2) % 2 ? RUMBLE_A : RUMBLE_B, FOG, fog));
    quad(X1 - R1 * 1.09, Y1, X1 - R1, Y1, X2 - R2, Y2, X2 - R2 * 1.09, Y2);
    quad(X1 + R1, Y1, X1 + R1 * 1.09, Y1, X2 + R2 * 1.09, Y2, X2 + R2, Y2);
    let rc = alt ? ROAD_A : ROAD_B;
    if (s.pool) rc = mix(rc, ROAD_LIT, s.pool * 0.55);
    G.fillStyle = rgb(mix(rc, FOG, fog));
    quad(X1 - R1, Y1, X1 + R1, Y1, X2 + R2, Y2, X2 - R2, Y2);
    if (i === START_SEG || i === FIN) {
      G.fillStyle = rgb(mix(CHECK, FOG, fog));
      for (let row = 0; row < 2; row++) {
        const ya = lerp(Y1, Y2, row / 2);
        const yb = lerp(Y1, Y2, (row + 1) / 2);
        const xa = lerp(X1, X2, row / 2);
        const xb = lerp(X1, X2, (row + 1) / 2);
        const ra = lerp(R1, R2, row / 2);
        const rb = lerp(R1, R2, (row + 1) / 2);
        for (let col = 0; col < 14; col++) {
          if ((col + row) % 2) continue;
          const u0 = -1 + col / 7;
          const u1 = -1 + (col + 1) / 7;
          quad(xa + u0 * ra, ya, xa + u1 * ra, ya, xb + u1 * rb, yb, xb + u0 * rb, yb);
        }
      }
      return;
    }
    const e1 = R1 * 0.016;
    const e2 = R2 * 0.016;
    G.fillStyle = rgb(mix(EDGE, FOG, fog));
    for (const sd of [-0.965, 0.965]) quad(X1 + sd * R1 - e1, Y1, X1 + sd * R1 + e1, Y1, X2 + sd * R2 + e2, Y2, X2 + sd * R2 - e2, Y2);
    if (i % 4 < 2) {
      G.fillStyle = rgb(mix(LANE, FOG, fog));
      for (const L of [-1 / 3, 1 / 3])
        quad(X1 + L * R1 - e1 * 0.8, Y1, X1 + L * R1 + e1 * 0.8, Y1, X2 + L * R2 + e2 * 0.8, Y2, X2 + L * R2 - e2 * 0.8, Y2);
    }
  }

  function pylonTheta(i: number, f: Frame) {
    const at = f.towers[i];
    const ph = towerPhase(at, f.t);
    if (ph === 'stand' || at === null) return 0;
    if (ph === 'warn') return 0.035 * Math.sin((f.t - at) * 38);
    if (ph === 'fall') {
      const u = Math.min(1, (f.t - at - WARN_S) / FALL_S);
      return 0.04 + (FALLEN - 0.04) * u * u;
    }
    return FALLEN;
  }

  function drawPylon(i: number, f: Frame) {
    const p = course!.pylons[i];
    const q = proj(p.z, p.side * TOWER_X);
    if (!q) return;
    const ph = towerPhase(f.towers[i], f.t);
    withClip(q.clip, () => {
      G.globalAlpha = 1 - q.fog * 0.9;
      const prev = p.prev >= 0 ? course!.pylons[p.prev] : null;
      const prevPh = prev ? towerPhase(f.towers[p.prev], f.t) : 'stand';
      if (prev && (ph === 'stand' || ph === 'warn') && (prevPh === 'stand' || prevPh === 'warn')) {
        G.strokeStyle = 'rgba(150,154,170,.3)';
        G.lineWidth = 1;
        for (const [ax, ay] of ARMS) {
          const a = proj(p.z, p.side * TOWER_X + ax / HALF, -ay);
          const b = proj(prev.z, prev.side * TOWER_X + ax / HALF, -ay);
          if (!a || !b) continue;
          G.beginPath();
          G.moveTo(a.X, a.Y);
          G.quadraticCurveTo((a.X + b.X) / 2, (a.Y + b.Y) / 2 + Math.abs(b.X - a.X) * 0.06 + (b.Y - a.Y) * 0.08, b.X, b.Y);
          G.stroke();
        }
      }
      G.save();
      G.translate(q.X, q.Y);
      G.rotate(-p.side * pylonTheta(i, f));
      G.scale(q.k, q.k);
      G.strokeStyle = p.falls && ph !== 'stand' ? '#a39690' : '#767a87';
      G.lineWidth = Math.max(13, 0.9 / q.k);
      G.beginPath();
      for (let j = 0; j < PYL.length; j += 4) {
        G.moveTo(PYL[j], PYL[j + 1]);
        G.lineTo(PYL[j + 2], PYL[j + 3]);
      }
      G.stroke();
      const on = ph === 'warn' || ph === 'fall' ? Math.floor(clock * 10) % 2 === 0 : Math.sin(clock * 2.6 + p.seg) > 0.3;
      if (on) {
        G.globalCompositeOperation = 'lighter';
        G.fillStyle = 'rgba(255,60,50,.35)';
        circ(0, -PH - 10, Math.max(70, 3 / q.k));
        G.fillStyle = '#ff4a3a';
        circ(0, -PH - 10, Math.max(24, 1.2 / q.k));
      }
      G.restore();
    });
  }

  function draw(f: Frame, dt: number) {
    if (!view.w || !bd) return;
    if (f.course !== course) {
      // Новая трасса — новая гонка: прошлые частицы прочь, а уже лёгшие опоры
      // и взорванные прицелы не должны пыхнуть все разом при входе посреди гонки.
      course = f.course;
      parts = [];
      rings = [];
      scorches = [];
      fired.clear();
      lastCam = -1;
      course.pylons.forEach((p, i) => {
        if (towerPhase(f.towers[i], f.t) === 'down') fired.add('p' + i);
      });
    }
    clock += dt;
    paintOn(ctx);
    const tgt = f.cars[f.cam];
    if (f.cam !== lastCam) {
      if (lastCam >= 0) fade = 1;
      camLat = tgt.x * HALF * 0.72;
      lastCam = f.cam;
    }
    applyEvents(f);
    stepFx(dt, f);

    const { w, h, dpr } = view;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    const sh = opts.reduced ? 0 : shake;
    ctx.translate((Math.random() - 0.5) * sh, (Math.random() - 0.5) * sh);
    skyOff += segAt(course, tgt.z).curve * (tgt.speed / VMAX) * dt * 40;
    drawBackdrop();

    const camZ = tgt.z - view.dp;
    const base = clamp(Math.floor(camZ / SEG), 0, NSEG - 2);
    const bp = clamp((camZ - base * SEG) / SEG, 0, 1);
    const end = Math.min(NSEG, base + DRAW);
    const segs = course.segs;
    let x = 0;
    let dx = -(segs[base].curve * bp);
    for (let i = base; i < end; i++) {
      cx1[i] = x;
      cx2[i] = x + dx;
      x += dx;
      dx += segs[i].curve;
    }
    const ti = clamp(Math.floor(tgt.z / SEG), base, end - 1);
    const tt = (tgt.z - ti * SEG) / SEG;
    camLat += (tgt.x * HALF * 0.72 - camLat) * Math.min(1, dt * 7);
    cam.z = camZ;
    cam.base = base;
    cam.end = end;
    cam.x = lerp(cx1[ti], cx2[ti], tt) + camLat;
    cam.y = view.camH + lerp(segs[ti].y1, segs[ti].y2, tt);

    let maxY = h + 30;
    for (let i = base; i < end; i++) {
      const s = segs[i];
      clipY[i] = maxY;
      const z1 = i * SEG - camZ;
      if (z1 < 40) continue;
      const s1 = view.f / z1;
      const s2 = view.f / (z1 + SEG);
      const X1 = w / 2 + (cx1[i] - cam.x) * s1;
      const Y1 = view.hy + (cam.y - s.y1) * s1;
      const X2 = w / 2 + (cx2[i] - cam.x) * s2;
      const Y2 = view.hy + (cam.y - s.y2) * s2;
      if (Y2 >= maxY) continue;
      drawSeg(i, X1, Y1, HALF * s1, X2, Y2, HALF * s2, z1);
      maxY = Y2;
    }

    // Предметы — от дальних к ближним; пометки на дороге — раньше того, что стоит на том же месте.
    const D: { d: number; fn: () => void }[] = [];
    const zMin = camZ + 60;
    const zMax = end * SEG;
    const put = (z: number, bias: number, fn: () => void) => {
      if (z > zMin && z < zMax) D.push({ d: z - camZ + bias, fn });
    };
    for (const l of course.lamps) put(l.z, 0, () => drawLamp(l.z, l.side));
    course.pylons.forEach((p, i) => {
      put(p.z, 0, () => drawPylon(i, f));
      const ph = towerPhase(f.towers[i], f.t);
      if (p.falls && (ph === 'warn' || ph === 'fall')) put(p.z, 4, () => drawZone(i));
    });
    for (const d of scorches) put(d.z, 6, () => drawScorch(d));
    course.mines.forEach((m, i) => {
      if (!f.gone[i]) put(m.z, 3, () => drawMine(i));
    });
    course.oils.forEach((o, i) => put(o.z, 3, () => drawOil(i)));
    for (const s of f.strikes) if (f.t >= s.at - STRIKE_S && f.t < s.at + 0.05) put(s.z, 2, () => drawStrike(s, f.t));
    for (const g of rings) put(g.z, 1, () => drawRing(g));
    for (const c of f.cars) {
      if (!c.dead) put(c.z, 5, () => drawBeam(c));
      put(c.z, 0, () => drawCar(c, f));
    }
    for (const pt of parts) put(pt.z, -1, () => drawPart(pt));
    put(FIN * SEG + 1, 0, drawGate);
    D.sort((a, b) => b.d - a.d);
    for (const it of D) {
      G.save();
      it.fn();
      G.restore();
    }

    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    if (flash > 0.01 && !opts.reduced) {
      G.fillStyle = `rgba(255,214,170,${flash})`;
      G.fillRect(0, 0, w, h);
    }
    if (fade > 0.01) {
      G.fillStyle = `rgba(5,5,5,${fade})`;
      G.fillRect(0, 0, w, h);
    }
    const vg = G.createRadialGradient(w / 2, h * 0.55, Math.min(w, h) * 0.45, w / 2, h * 0.55, Math.max(w, h) * 0.8);
    vg.addColorStop(0, 'rgba(0,0,0,0)');
    vg.addColorStop(1, 'rgba(0,0,0,.45)');
    G.fillStyle = vg;
    G.fillRect(0, 0, w, h);
  }

  return { resize, draw };
}
```

```ts
import {
  buildCourse,
  CAR_IDS,
  COUNTDOWN,
  createBot,
  createRace,
  IDLE,
  rng,
  step,
  STEP,
  type Bot,
  type RaceState,
  type Rnd,
  type SimEvent,
} from '@/entities/race';
import type { Frame, FrameSource } from './scene';

/**
 * Гонка трёх ботов прямо в браузере — за гаражом и на карточке витрины. Та же
 * симуляция, что на сервере, только без сервера: показ, а не игра. Без огней
 * старта; кончилась — через 1,2 с новая трасса.
 */
export function createAttract(): FrameSource {
  let s: RaceState;
  let bots: Map<number, Bot>;
  let rnd: Rnd;
  let cam = 0;
  let acc = 0;
  let overFor = 0;
  const reset = () => {
    const seed = Math.floor(Math.random() * 2 ** 31);
    const cars = [...CAR_IDS].sort(() => Math.random() - 0.5);
    s = createRace(buildCourse(seed), cars.map((car, slot) => ({ slot, car })));
    s.t = COUNTDOWN;
    rnd = rng(seed ^ 0x5bd1e995);
    bots = new Map(s.cars.map((c) => [c.slot, createBot(rnd, c.x)]));
    cam = 0;
    acc = 0;
    overFor = 0;
  };
  reset();
  return {
    next(dt: number): Frame {
      const ev: SimEvent[] = [];
      acc += Math.min(dt, 0.1);
      while (acc >= STEP) {
        step(s, STEP, { input: () => IDLE, rnd, bots }, ev);
        acc -= STEP;
      }
      if (s.over && (overFor += dt) > 1.2) reset();
      const c = s.cars[cam];
      if (c.dead && s.t - c.deadAt > 1.8) {
        const alive = s.cars.filter((x) => !x.dead).sort((a, b) => b.z - a.z)[0];
        if (alive) cam = alive.slot;
      }
      return {
        course: s.course,
        t: s.t,
        cars: s.cars.map((x) => ({ ...x, tag: null, brake: false })),
        cam,
        gone: s.gone,
        towers: s.towers,
        strikes: s.strikes,
        events: ev,
      };
    },
  };
}
```

```tsx
'use client';

import { useEffect, useLayoutEffect, useRef } from 'react';
import { createRenderer, type FrameSource } from '../lib/scene';

/**
 * Холст сцены гонки. Цикл кадров — свой, мимо React: кадр рисуется из
 * `source.next(dt)`. Вне экрана и у фоновой вкладки цикл стоит. `fps` —
 * потолок частоты: карточке витрины хватает 30.
 */
export function RaceCanvas({
  source,
  fps = 60,
  className,
  label,
}: {
  source: FrameSource;
  fps?: number;
  className?: string;
  label?: string;
}) {
  const ref = useRef<HTMLCanvasElement>(null);
  const src = useRef(source);
  useLayoutEffect(() => {
    src.current = source;
  });

  useEffect(() => {
    const canvas = ref.current;
    if (!canvas) return;
    const r = createRenderer(canvas, { reduced: matchMedia('(prefers-reduced-motion: reduce)').matches });
    const fit = () => {
      const b = canvas.getBoundingClientRect();
      if (b.width && b.height) r.resize(b.width, b.height, Math.min(window.devicePixelRatio || 1, 1.75));
    };
    const ro = new ResizeObserver(fit);
    ro.observe(canvas);
    fit();
    let visible = true;
    const io = new IntersectionObserver(([e]) => {
      visible = e.isIntersecting;
    });
    io.observe(canvas);
    const minDt = 1 / fps;
    let last = performance.now();
    let raf = 0;
    const loop = (now: number) => {
      raf = requestAnimationFrame(loop);
      if (!visible || document.hidden) {
        last = now;
        return;
      }
      const dt = (now - last) / 1000;
      if (dt < minDt * 0.85) return;
      last = now;
      const f = src.current.next(Math.min(dt, 0.1));
      if (f) r.draw(f, Math.min(dt, 0.1));
    };
    raf = requestAnimationFrame(loop);
    return () => {
      cancelAnimationFrame(raf);
      ro.disconnect();
      io.disconnect();
    };
  }, [fps]);

  return <canvas ref={ref} className={className} aria-label={label} role={label ? 'img' : undefined} aria-hidden={label ? undefined : true} />;
}
```

```ts
import {
  buildCourse,
  COUNTDOWN,
  interpCars,
  predictCar,
  progressOf,
  raceClock,
  ranking,
  type Cause,
  type Course,
  type InputLog,
  type LiveStore,
  type SimEvent,
  type Strike,
} from '@/entities/race';
import type { CarView, Frame, FrameSource } from '@/widgets/race-scene';

export type FeedText = { k: 'hit'; cause: Cause; dmg: number } | { k: 'out'; cause: Cause } | { k: 'finish'; first: boolean } | { k: 'slide' };

export interface LiveHud {
  /** Время гонки по часам сервера. */
  t: number;
  /** 1–3 — красные огни, 4 — зелёный, 0 — огней нет. */
  lights: number;
  place: number;
  speed: number;
  hp: number;
  me: number | null;
  meDead: boolean;
  cam: number;
  progress: number[];
  dead: boolean[];
  feed: { id: number; slot: number; text: FeedText }[];
}

export interface LiveSource extends FrameSource {
  hud: LiveHud | null;
}

/**
 * Кадр идущей гонки. Две шкалы времени: опасности и своя машина — на «сейчас»
 * по часам сервера (своя — предсказанием от последнего снимка, расхождение
 * гаснет за 0,1 с); чужие машины и события снимков — на «сейчас − задержка
 * суда − 0,1 с», где для них уже есть два снимка.
 */
export function createLiveSource(store: LiveStore, log: InputLog, anon: string): LiveSource {
  let course: Course | null = null;
  let seed = -1;
  let raceId = '';
  let lastSnapT = -1;
  let err = { x: 0, z: 0 };
  let shown: { x: number; z: number } | null = null;
  const strikes = new Map<number, Strike>();
  let feed: (LiveHud['feed'][number] & { at: number })[] = [];
  let feedSeq = 0;

  const src: LiveSource = {
    hud: null,
    next(dt): Frame | null {
      const v = store.view;
      const r = v?.race;
      const dyn = r?.dyn;
      if (!v || !r || !dyn || r.startAt == null) return null;
      if (r.id !== raceId) {
        raceId = r.id;
        if (r.seed !== seed) {
          seed = r.seed;
          course = buildCourse(r.seed);
        }
        strikes.clear();
        feed = [];
        lastSnapT = -1;
        err = { x: 0, z: 0 };
        shown = null;
      }
      const c = course!;
      const now = raceClock(v);
      const tOthers = now - v.config.delayMs / 1000 - 0.1;
      const me = r.me;
      const nameOf = (slot: number) => r.racers.find((x) => x.slot === slot)?.name ?? anon;

      const others = interpCars(store.snaps, tOthers) ?? dyn.cars;
      const cars: CarView[] = others.map((o) => ({ ...o, tag: o.slot === me ? null : nameOf(o.slot), brake: false }));
      let gone = dyn.gone;
      const shownEvents: SimEvent[] = [];

      if (me !== null && !dyn.cars[me].dead && !dyn.cars[me].finished) {
        const pev: SimEvent[] = [];
        const pred = predictCar(c, dyn, me, log, now, pev);
        if (dyn.t !== lastSnapT) {
          if (shown) {
            err = { x: shown.x - pred.car.x, z: shown.z - pred.car.z };
            if (Math.abs(err.x) > 0.6 || Math.abs(err.z) > 1500) err = { x: 0, z: 0 };
          }
          lastSnapT = dyn.t;
        }
        const k = Math.exp(-dt / 0.1);
        err = { x: err.x * k, z: err.z * k };
        const own = { ...pred.car, x: pred.car.x + err.x, z: pred.car.z + err.z };
        shown = { x: own.x, z: own.z };
        cars[me] = { ...own, tag: null, brake: log.at(now).brake };
        gone = dyn.gone.map((g, i) => g || pred.gone[i]);
        for (const e of pev) if (e.k === 'boom') shownEvents.push(e);
      } else shown = null;

      for (const e of store.take(tOthers)) {
        shownEvents.push(e);
        let text: FeedText | null = null;
        if (e.k === 'hit' && e.dmg > 0) text = { k: 'hit', cause: e.cause, dmg: e.dmg };
        else if (e.k === 'out') text = { k: 'out', cause: e.cause };
        else if (e.k === 'finish') text = { k: 'finish', first: e.first };
        else if (e.k === 'slide' && e.slot === me) text = { k: 'slide' };
        if (text && 'slot' in e) feed.push({ id: ++feedSeq, slot: e.slot, text, at: now });
      }
      feed = feed.filter((x) => now - x.at < 5).slice(-4);

      for (const st of dyn.strikes) strikes.set(st.id, st);
      for (const [id, st] of strikes) if (st.at < now - 0.5) strikes.delete(id);

      let cam = me ?? 0;
      const mine = me !== null ? dyn.cars[me] : null;
      if (!mine || (mine.dead && tOthers - mine.deadAt > 1.8)) {
        const lead = cars.filter((x) => !x.dead).sort((a, b) => b.z - a.z)[0];
        if (lead) cam = lead.slot;
      }

      const order = ranking(cars);
      src.hud = {
        t: now,
        lights: now < 0.7 ? 1 : now < 1.4 ? 2 : now < COUNTDOWN ? 3 : now < COUNTDOWN + 0.9 ? 4 : 0,
        place: me !== null ? order.findIndex((x) => x.slot === me) + 1 : 0,
        speed: me !== null ? cars[me].speed : 0,
        hp: mine?.hp ?? 0,
        me,
        meDead: !!mine?.dead,
        cam,
        progress: cars.map(progressOf),
        dead: cars.map((x) => x.dead),
        feed: feed.map(({ id, slot, text }) => ({ id, slot, text })),
      };
      log.prune(dyn.t - 0.5);

      return { course: c, t: now, cars, cam, gone, towers: dyn.towers, strikes: [...strikes.values()], events: shownEvents };
    },
  };
  return src;
}
```

```tsx
  const meRacer = hud.me !== null ? r.racers.find((x) => x.slot === hud.me) : undefined;
  const nameOf = (slot: number) => {
    const p = r.racers.find((x) => x.slot === slot);
    return p?.me ? t('you') : (p?.name ?? t('anon'));
  };
  const say = (x: FeedText) =>
    x.k === 'hit'
      ? t(`feed.${x.cause}`, { dmg: x.dmg })
      : x.k === 'out'
        ? t('feed.out', { cause: t(`cause.${x.cause}`) })
        : x.k === 'finish'
          ? t(x.first ? 'feed.finishFirst' : 'feed.finish')

      <div className="rc-hud-top">
        <div className="rc-place">

        ))}
      </div>
      {watching && (
        <div className="rc-spect">
          <b>{t('hud.out')}</b>
          <span>{hud.cam === hud.me ? t('hud.watchNext') : t('hud.watching', { name: nameOf(hud.cam) })}</span>
        </div>
      )}
      {meRacer && (
        <div className="rc-hud-bottom">
          <div>
            <div className="rc-k">{t('hud.hp', { car: t(`cars.${meRacer.car}.name`) })}</div>

            <small>{t('hud.kmh')}</small>

        </div>

        <div className="rc-lights" aria-hidden>

            <i key={n} className={hud.lights === 4 ? 'go' : n <= hud.lights ? 'on' : undefined} />
          ))}
        </div>
      )}
    </div>
  );
}
```

```tsx
'use client';

import { useEffect, useLayoutEffect, useRef, useState } from 'react';
import { useTranslations } from 'next-intl';
import { InputLog, raceClock, type Input, type LiveStore, type RaceView } from '@/entities/race';
import { RaceCanvas } from '@/widgets/race-scene';
import { createLiveSource, type LiveHud } from '../model/liveSource';
import { Pad } from '../model/pad';
import { Hud } from './Hud';
import { Result } from './Result';
import { TouchPad } from './TouchPad';

const KEYS: Record<string, 'left' | 'right' | 'brake'> = {
  ArrowLeft: 'left',
  KeyA: 'left',
  ArrowRight: 'right',
  KeyD: 'right',
  ArrowDown: 'brake',
  KeyS: 'brake',
  Space: 'brake',
};

/**
 * Идущая гонка: сцена, руль, цифры, итог. Нажатие уходит сразу и пульсом раз в
 * 250 мс (без пульса сервер через секунду считает кнопки отпущенными); цифры
 * перечитываются из источника кадров 10 раз в секунду, а не на каждом кадре.
 */
export function Live({
  view,
  store,
  send,
  onChange,
}: {
  view: RaceView;
  store: LiveStore;
  send: (t: number, input: Input) => void;
  onChange: () => void;
}) {
  const t = useTranslations('race');
  const sendRef = useRef(send);
  useLayoutEffect(() => {
    sendRef.current = send;
  });
  const [log] = useState(() => new InputLog());
  const [src] = useState(() => createLiveSource(store, log, t('anon')));
  const [pad] = useState(
    () =>
      new Pad((input) => {
        const v = store.view;
        if (!v) return;
        const at = raceClock(v);
        log.push(at, input);
        sendRef.current(at, input);
      }),
  );
  const over = view.phase === 'over';

  useEffect(() => {
    if (over) return;
    const down = (e: KeyboardEvent) => {
      const k = KEYS[e.code];
      if (!k) return;
      e.preventDefault();
      pad.set(k, true);
    };
    const up = (e: KeyboardEvent) => {
      const k = KEYS[e.code];
      if (k) pad.set(k, false);
    };
    const blur = () => pad.release();
    const beat = setInterval(() => {
      const v = store.view;
      if (v) sendRef.current(raceClock(v), pad.input);
    }, 250);
    window.addEventListener('keydown', down);
    window.addEventListener('keyup', up);
    window.addEventListener('blur', blur);
    return () => {
      clearInterval(beat);
      window.removeEventListener('keydown', down);
      window.removeEventListener('keyup', up);
      window.removeEventListener('blur', blur);
      pad.release();
    };
  }, [over, pad, store]);

  const [hud, setHud] = useState<LiveHud | null>(null);
  useEffect(() => {
    const id = setInterval(() => setHud(src.hud ? { ...src.hud } : null), 100);
    return () => clearInterval(id);
  }, [src]);

  return (
    <>
      <RaceCanvas source={src} className="rc-canvas" label={t('sceneLabel')} />
      {hud && !over && <Hud hud={hud} view={view} />}
      {!over && <TouchPad pad={pad} />}
      {over && <Result view={view} onChange={onChange} />}
    </>
  );
}
```

```js
// Сквозной прогон гонки: двое живых + бот, руль случайными нажатиями, сверка монет.
const { io } = require('socket.io-client');
const API = process.env.API || 'http://localhost:8091';
const users = [
  { email: 'pw-tester@example.com', password: 'pw-tester-123' },
  { email: 'race-e2e@example.com', password: 'race-e2e-123', name: 'race-e2e' },
];
const j = async (path, token, body) => {
  const r = await fetch(API + path, {
    method: body ? 'POST' : 'GET',
    headers: { 'content-type': 'application/json', ...(token ? { authorization: `Bearer ${token}` } : {}) },
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = await r.json().catch(() => ({}));
  if (!r.ok) throw new Error(`${path} ${r.status} ${JSON.stringify(data)}`);
  return data;
};
async function login(u) {
  try {
    return (await j('/auth/login', null, u)).accessToken;
  } catch {
    return (await j('/auth/register', null, u)).accessToken;
  }
}
(async () => {
  const tokens = await Promise.all(users.map(login));
  const before = await Promise.all(tokens.map((t) => j('/api/coins', t)));
  const a = await j('/api/games/race/join', tokens[0], { stake: 10, car: 'buggy' });
  const b = await j('/api/games/race/join', tokens[1], { stake: 10, car: 'tank' });
  if (a.race.id !== b.race.id) throw new Error('разные лобби');
  const id = a.race.id;
  let final = null;
  const socks = tokens.map((token) => {
    const s = io(`${API}/games`, { path: '/api/games/socket.io', addTrailingSlash: false, auth: { token } });
    let view = null;
    s.on('connect', () => s.emit('join_table', `race:${id}`));
    s.on('race_state', (v) => {
      view = v;
      if (v.phase === 'over') final = v;
    });
    const beat = setInterval(() => {
      if (!view?.race?.startAt) return;
      const t = (Date.now() + (view.serverNow - Date.now()) - view.race.startAt) / 1000;
      const r = Math.random();
      s.emit('race_input', { raceId: id, t, l: r < 0.3, r: r > 0.7, b: false });
    }, 200);
    s.on('disconnect', () => clearInterval(beat));
    return { s, beat };
  });
  const t0 = Date.now();
  while (!final && Date.now() - t0 < 150_000) await new Promise((r) => setTimeout(r, 500));
  socks.forEach(({ s, beat }) => (clearInterval(beat), s.disconnect()));
  if (!final) throw new Error('гонка не закончилась за 150 с');
  const after = await Promise.all(tokens.map((t) => j('/api/coins', t)));
  console.log('итог', JSON.stringify(final.race.result), 'участники', JSON.stringify(final.race.racers));
  console.log('монеты до', before.map((x) => x.balance ?? x), 'после', after.map((x) => x.balance ?? x));
})().catch((e) => {
  console.error(e);
  process.exit(1);
});
```
