Скрипты и скриншоты — scratchpad сессии `qa-b/`. Пользователь pw-tester@example.com, сессии

### Наблюдения
- Тейк вне видимого диапазона цены не виден и не тянется (под RSI); автофита под уровни нет.
- После отмены первого лимита сетки у второго stopAfter = цена отменённого (34789.70).
- Смены плеча открытой позиции в UI не нашлось; «10×» влияет только на следующий ордер.
- r включает комиссии (−1.26…−1.37R при стопе), подпись «stop −100.00» без комиссии — по документации.
- В «Ордерах» колонка Time — реальное время установки, а не время сессии.
- Размер позиции в таблице — в USDT (нотионал), не в монете.

## Работает
1. Long: стоп (pnl −137.33, r −1.37) и тейк (+7.302) по формуле с комиссией 0.055 %×2;
   баланс = 10000 + Σpnl; плашки исчезают; 3 запроса, без зацикливания.
2. Short: перенос стопа перетаскиванием и окном сохраняется; стоп сработал по новой цене
   (pnl −38.36); окно блокирует стоп по неверную сторону.
3. Частичное закрытие лимитом: остаток 0.138 на плашке и в таблице, риск стопа −50; остаток
   рынком двумя частями, итог −25.24 = сумме выходов.
4. Сетка 5 тейков с переносом стопа: безубыток после 1-го, далее на цене предыдущего; итог
   +33.2798 = «Profit if all fill»; новая сетка заменяет лимиты; отмена Cancel и ✕ работает;
   первый тейк = входу блокируется; выход по безубытку сошёлся.
5. Закрытие рынком частями — деньги сходятся (баг 3 — только подсказка).
6. Плечо 25×: lev=25 на сервере, ликвидация 25386.55; отказ по марже понятным текстом.
7. Хедж long+short: всё независимо, Σpnl = Δбаланса (−269.7292).
8. Спам Long/Short и Market close на ×32: одна сделка/одно закрытие, остатки ≥ 0, Σpnl = Δбаланса.
9. Longtask > 100 мс: 1–3 за прогон (105–207 мс), при загрузке и исполнениях; pageerror только
   баги 1–2; зацикливания запросов нет.
