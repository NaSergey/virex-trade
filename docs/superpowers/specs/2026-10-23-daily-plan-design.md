# План дня владельца в админке

Запрос владельца 2026-10-23: доска задач на каждый день; в Telegram в начале блока приходит
«пора заниматься бектестом / английским…» с кнопками «сажусь за работу», «забил», «иду гулять»;
план можно составлять и менять; отчётность — насколько держусь плана, тоже с уведомлениями в TG.

## Модель

- **Шаблон недели** (`plan_blocks`): время, что делаю, вид (фиксированный список
  `categories.ts` — статистика по свободному тексту разъехалась бы), пункты, дни недели битами,
  флажок «отслеживать» (сон и еду не отслеживают — нет напоминания и места в отчёте).
- **День** (`plan_days` + `plan_items`) собирается из шаблона при первом открытии или когда до
  него дошёл `worker`, дальше живёт сам. Правка шаблона пересобирает будущие дни без ручных
  правок; сегодняшний — кнопкой «Пересобрать» (уходят только блоки без ответа и без напоминания).
  Прошлый день без строки не собирается — задним числом плана не было.
- **Статус** — ответ: planned, started, done, partial, skipped, walk. **Исход выводится**
  (`plan-stats.ts`): planned после конца — «без ответа», started после конца — «итога нет».
- Пояс — в настройках (`Europe/Moscow` по умолчанию); страница предлагает пояс устройства, но
  сама его не меняет. Блок через полночь — двумя блоками.

## Telegram (`PlanBotService`, роль `worker`, тик 30 с)

- Начало блока (минус `leadMin`) — сообщение с пунктами и кнопками. Кнопка меняет статус и
  перерисовывает сообщение тем же `itemMessage`.
- Конец: «в работе» — старое сообщение без кнопок, новым — «как прошло?» (сделал / частично /
  не сделал); без ответа — старое сообщение тихо получает кнопки «как было на самом деле».
- Утренний план и вечерний отчёт по времени из настроек (опоздавшие больше чем на 3 ч не
  шлются); в воскресенье к отчёту — неделя. Команды `/plan`, `/report`, `/week`.
- Только чат владельца (`OWNER_EMAIL`), как у бэкапа базы. Каждая отправка сначала ставит
  отметку условным `updateMany`: потерянное сообщение лучше двух.

## Отчётность

Соблюдение = сделал 1, частично / итога нет ½, забил / гулял / без ответа 0, среди
отслеживаемых блоков, чьё время прошло или на которые ответили. Серия — дни подряд от 70 %; дни
без плана её не рвут, недобор сегодня — тоже. Опоздание — от начала блока до «сажусь»,
пришёл раньше — 0.
